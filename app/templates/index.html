Extract URL characteristics and combine model predictions with rule-based warning indicators.

Event Classification

Classify numerical SILRAD event features using a trained Random Forest model.

ABOUT THE PROJECT

Understanding threats through intelligent analysis.

CyberShield is a final-year academic project exploring machine-learning approaches to phishing URL analysis, malware file inspection, and ransomware-related event classification. Its modules are prototypes and should not be used as the sole basis for security decisions.
